# project_x

Что сделано

- Регистрация и вход.
- Главная страница с лентой постов.
- Страница создания поста.
- Страница просмотра поста с комментариями.
- Страница профиля пользователя с возможностью редактирования.
- Валидация форм на фронтенде и на бэкенде.
- Обработка ошибок (400, 401, 403, 404, 409) с отображением сообщений пользователю.
- Ролевая система (обычный пользователь и администратор).
- Контейнеризация (Docker) и запуск фронтенда и бэкенда через docker-compose.

Как запустить

а) Бэкенд через PowerShell
1. Перейти в папку бэкенда:
cd backend
2. Установить пакет:
pip install pydantic-settings
3. Установить зависимости:
pip install -r requirements.txt
4. Запустить сервер:
uvicorn app.main:app --reload
5. Открыть документацию API в браузере:
http://127.0.0.1:8000/docs

б) Фронтенд 
1. Установить Node.js (поставить галочку "Add to PATH" (важно!))
2. Запустить Powershell в папке frontend
3. Создать package.json:
npm create vite@latest frontend -- --template react-ts
4. Установить пакеты:
cd frontend новая строка
npm install
5. Добавить react-router-dom:
npm install react-router-dom
6. Запустить dev‑сервер:
npm run dev
7. Открыть приложение в браузере:
http://127.0.0.1:5173
